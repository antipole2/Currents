= Technical guide for the Currents script

As this script is quite complex, this guide documents key aspects of how it works.
It would be wise to read this before modifying or maintaining the Housekeeper script.


== Context sensitive context menus

The script is controlled through sub-menus of the Currents route context menu.
These are created dynamically, once the context is known.

The script sets up a repeating callback to the function `mouseEvent` when there is a right-click (or control-click).
This fuction examines the context and creates the route context menu with the appropraite sub-menus.
Each sub-menu sets up a callback to the appropriate handler.

== The control block

The script keeps data about each route or routepoint in a control block like `route.cb`.
This always includes .state, which is a text string which is one of:

* NCP route has no current predictions
* HCP route has (or has had) current predictions inserted
* ICC route is a freestanding prediction, displayed in purple by default
* CCB routepoint has current prediction for this point and time

Here is an example for a free-standing prediction:
`cb={“state”:”ICC”,”routeGUID”:”090e91e2-3717-4fc2-8d10-f98720e418a3”,”fromGUID”:”20026a00-fcf9-4cff-bfbb-ac1a13290e03”,”toGUID”:”6c56f0c7-7fb4-4bac-a031-348b495f3e2b”,”hash”:3921783284}`

* routeGUID records the parent route for which it is a prediction and into which it could be inserted
* fromGUID is the routepoint GUID within the parent route after which it should be inserted
* toGUID is the routepoint GUID within the parent route before which it should be inserted

== Storing the control block within OpenCPN

These additional attributes of a route or routepoint have no equivalent in OpenCPN.
In order to save them, they are stored within the objects .description attribute as a JSON string.
They are stored after any other text within the description attribute.

Access to routes in OpenCPN is all through the plugin's Route object.
(See the User Guide for a description of these.)
These include `.add`, `.add` and `.get` methods to access OpenCPN.

The function `extendedRouteConstructor` extends the Route object to include additional methods `.addWithCb`, `.addWithCb` and `.getWithCb`.
When saving to OpenCPN, these handle stashing cb into .description.
When fetching a route from OpenCPN, the .getWithCb method gets the route, unstashes the cb and adds it to the route inthe script.
